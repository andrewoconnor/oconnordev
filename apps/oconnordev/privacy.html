Privacy policy

Last updated: October 17, 2026

Scope

This policy covers the Google OAuth application that Andrew O'Connor operates for his own personal assistant. The application is not offered to the public. Only Andrew O'Connor's own Google account uses it.

Data the application accesses

With the owner's consent, the application requests read-only access to the owner's Gmail and Google Calendar through Google APIs. It does not request permission to send, change or delete mail or calendar events.

How the data is used

The application reads data only to answer the owner's own requests to his assistant. Requests go through Amazon Bedrock AgentCore in the owner's AWS account. AgentCore Identity stores the OAuth tokens encrypted. The AI model that the assistant uses processes the content only to produce the requested answer.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing and retention

The data is not sold, not shared with other parties, not used for advertising and not used to train AI models. The application keeps no copy of mail or calendar content. Operational logs keep request metadata for a short time.

Revoking access

Remove the application's access at any time from your Google Account permissions.
